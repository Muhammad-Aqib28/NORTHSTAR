# NORTHSTAR — Explore Beyond

NORTHSTAR is a travel and tourism website created using HTML5 and CSS3. It helps visitors explore travel destinations, Pakistan tours, packages, hotels, adventures, travel blogs, and photography.

## Features
- 10 linked website pages
- Travel destinations and Pakistan tours
- Tour packages and hotel information
- Adventure and travel blog sections
- Image gallery and contact page
- Responsive styling for different screen sizes

## Technologies Used
- HTML5
- CSS3
- GitHub for source-code management
- Netlify for free website hosting

## Pages
Home, Destinations, Pakistan Tours, Packages, Hotels, Adventures, Blog, About, Gallery, and Contact.
