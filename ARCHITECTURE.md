# NORTHSTAR — Website Architecture

## Project Overview
NORTHSTAR is a travel and tourism website designed to help users explore destinations, tour packages, hotels, adventures, and travel articles.

## Number of Pages
The website contains 10 HTML pages:
1. Home — `index.html`
2. Destinations — `destinations.html`
3. Pakistan Tours — `pakistan-tours.html`
4. Packages — `packages.html`
5. Hotels — `hotels.html`
6. Adventures — `adventures.html`
7. Blog — `blog.html`
8. About — `about.html`
9. Gallery — `gallery.html`
10. Contact — `contact.html`

## Navigation
A navigation menu connects the main pages, allowing users to move between sections of the website.

## CSS Usage
HTML is used for page structure, while CSS controls layout, colors, typography, spacing, and responsive styling. The project uses separate stylesheets for general styling and specific sections, including packages, adventures, gallery, contact, about, blog, and Pakistan tours.

## Technologies
- HTML5
- CSS3

No JavaScript is used in this assignment.
